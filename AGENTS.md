# Project

Masjid Manager Web — Arabic RTL app for managing mosque students in Jasreen (جسرين).

## Stack

Next.js 16.3.2, React 19, Tailwind CSS v4, TypeScript, Zod, Axios, Leaflet, MDX Editor, Lucide icons.

## Commands

```bash
npm run dev          # start dev server (port 3000)
npm run build        # production build
npm run lint         # eslint (next core-web-vitals + typescript)
```

No `tsc`, `prettier`, `test`, or `format` scripts exist.

## Structure

- `app/(public)/` — unauthenticated routes: landing, login, register, mosques, posts
- `app/(dashboard)/` — protected routes, role-gated by layout:
  - `/admin` → SYSTEM_ADMIN
  - `/mosque/[mosqueId]` → MOSQUE_MANAGER
  - `/teacher/[circleId]` → CIRCLE_TEACHER
  - `/parent` → PARENT
- `lib/features/` — domain modules (auth, mosque, circle, student, attendance, post, parent), each with `types.ts`, `schemas/`, `services/`
- `lib/api/client.ts` — two axios instances: `api` (public) and `apiClient` (auto-attaches Bearer token, redirects on 401)
- `components/` — UI organized by domain (dashboard, mosque, student, etc.)
- `config/dashboard-navigation.ts` — role-based sidebar nav definitions
- `context/toast.tsx` — `useToast()` hook + `ToastProvider`

## Conventions

- **RTL Arabic UI** — `lang="ar"`, `dir="rtl"` on `<html>`/`<body>`. Font: Tajawal (Arabic) + Geist Mono.
- **Tailwind v4** — uses `@theme` in `globals.css`, not `tailwind.config.*`. Custom color palette: primary, secondary, success, warning, danger, accent, neutral.
- **Server components by default** — add `"use client"` only when needed. Services use `"use server"`.
- **Path alias**: `@/*` maps to project root.
- **Auth**: JWT in httpOnly cookie (set server-side) + `localStorage` fallback (client interceptor). `apiClient` auto-redirects to `/login` on 401 or missing token.
- **Validation**: Zod schemas in `lib/features/*/schemas/`.
- **No caching** on dashboard: `export const dynamic = "force-dynamic"`.
- `LayoutProps<"/">` is the Next.js type for layout component props.
- Images from `next.config.ts` `remotePatterns`: i.pravatar.cc, images.unsplash.com, i.pinimg.com, cdn.sanity.io, quran.com, res.cloudinary.com.
